# Licensing policy

The public Commons separates licenses by artifact class because one license is not optimal for every object.

<!-- GENERATED:license-policy:start -->
- **Software and build tooling:** Apache License 2.0 (`Apache-2.0`).
- **Original human-readable editorial/scientific content and original site media:** Creative Commons Attribution 4.0 International (`CC-BY-4.0`).
- **Factual/catalog metadata intended for machine reuse:** Creative Commons CC0 1.0 Universal (`CC0-1.0`).
<!-- GENERATED:license-policy:end -->
Third-party sources remain under their own terms. Linking, citation, or metadata about a third-party work does not relicense that work.

This is a project policy, not legal advice. Before a 1.0 institutional release, independent counsel should review contributor terms, jurisdictional implications, and any media whose licensing differs from these defaults.
