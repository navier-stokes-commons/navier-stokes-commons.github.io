# Mission Authoring

A mission should exist only when the question is durable enough to support multiple bounded quests.

Required fields are specified by `schemas/mission.schema.json`. Before adding a mission, check for duplication, cite the public starting point, specify what would count as success, and identify who can review the result.

Community-authored missions begin as `public-rfc`. Do not manufacture certainty by writing an open question in declarative solved language. Where a starting point is a reasoning constraint rather than a sourced fact, label it as such.
