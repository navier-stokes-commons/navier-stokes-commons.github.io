# Glossary

**Mission** ; A public research question with sources, scope, suggested contributor types, and explicit acceptance checks.

**Attempt** ; A non-exclusive declaration that a person, team, or agent is working on a mission. It does not reserve the mission.

**Artifact** ; The work product: proof, formalization, code, dataset, numerical experiment, review, translation, explanation, design, or documented negative result.

**Evidence** ; Reproducible material showing what the artifact establishes and what it does not establish.

**Review** ; Independent checking, reproduction, criticism, falsification, source correction, translation review, or domain review.

**Accepted record** ; A reviewed contribution merged into canonical public data. The site then republishes it automatically.

**Side quest** ; A proposed new public question. A side quest must be scoped, sourced, and given acceptance conditions before it becomes a mission.

**Canonical English acceptance criteria** ; The current binding scientific wording for acceptance checks when a localized scientific translation has not been independently reviewed.
