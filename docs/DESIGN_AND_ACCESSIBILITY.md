# Public interface principles

The public interface optimizes for comprehension, research credibility, low bandwidth, accessibility, and durable machine readability.

- Real scientific notation is preferred to decorative pseudo-scientific imagery.
- Information hierarchy comes from typography, spacing, rules, and content order rather than glass cards or ornamental gradients.
- Essential information and navigation work without JavaScript.
- JavaScript enhancement is finite, optional, and tied to real content.
- The UI uses system fonts only; mathematical notation uses semantic MathML and a local mathematical font stack when available.
- Mission indexes are lists because the primary operation is comparison and selection, not browsing products in cards.
- The target is WCAG 2.2 Level AA; actual independent conformance still requires browser/assistive-technology and disabled-user review.
