# Review and Acceptance Procedure

For each result:

1. Freeze the exact artifact identity.
2. Verify the parent quest and mission are canonical.
3. Evaluate each acceptance condition separately.
4. Reproduce executable evidence when the quest requires it.
5. Check source and semantic correspondence, not only syntax or build success.
6. Record reviewer competence, independence, conflicts, verdict, and residual uncertainty.
7. If changes are requested, preserve the review and evaluate the revision as a new artifact version.
8. On acceptance, add contribution and review records to canonical public data and rebuild.

A maintainer may reject malformed or unsafe submissions without scientific adjudication. Rejection for scientific insufficiency should identify the failed acceptance conditions.
