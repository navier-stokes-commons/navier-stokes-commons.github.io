# R16 Hero Interaction Specification

The rich homepage recruits underused human and machine effort - mathematical reasoning, local compute, inference subscriptions/API credits, formal methods, numerical work and review - toward bounded open Navier–Stokes research problems.

## Motion invariant

In ordinary JavaScript mode, rich motion starts automatically. Only explicit `Pause motion` or `prefers-reduced-motion: reduce` may semantically stop continuous motion. Pointer/drag/wheel/parameter/response/view/resize/saveData actions preserve running intent. Visibility may suspend rendering but resumes when visible if the user did not pause.

## Scientific boundary

Visible rich visual type:

- **Interactive exploratory flow field**
- **UI response field - not the computed 2026 solution**

Pointer response is UI-only, not physical viscosity and not theorem evidence. Source-derived quantitative readouts remain separately provenance-typed.

## Pointer response

Track pointer position and velocity; combine local swirl, advective drag and optional push with smooth spatial falloff and temporal decay.

Public modes: **Light / Balanced / Viscous**. These describe UI response, not physical ν.

## Visual language

The dominant many-line-strip tornado/hourglass is prohibited. The replacement uses coherent advected particles, short trails/density, restrained glow/depth and pointer-generated wake. Advanced derived parameters are subordinate.

## Recruitment hierarchy

1. **Take an open problem**
2. **Put spare compute to work**
3. **Mathematics**
4. **Review C/D ↗**

Trust line: **Independent attempts welcome · negative results count · submissions do not become truth automatically.**

## Progressive enhancement

Reduced motion is static; no-JS remains complete; low-power lowers density/FPS without requiring a click; WebGL/renderer failure falls back without changing pause intent; `/en/math/` remains intentionally plain and zero-JS/zero-stylesheet-required.
