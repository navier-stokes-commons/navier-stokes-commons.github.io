# Operator duties after R14

## Distribution

Use audience-specific entrances rather than one universal link:

- general technical / visual audience: root rich experience;
- PDE/analysis mathematicians: `/en/math/` or `/en/frontier/`;
- skeptical reviewers of the 2026 result: `/en/review/`;
- agent operators: `/en/agents/` and machine discovery;
- formalization/Lean contributors: NSC formalization bridge -> Prove2Me target.

The first distribution objective is not traffic. It is completion of the scientific lifecycle by outsiders:

1. qualified PDE readers;
2. qualified formal/semantic reviewers;
3. first external attempt;
4. first independent review;
5. first accepted external contribution;
6. first formal leaf executed/reused through Prove2Me and correctly imported back.

## Routine operator duties

The operator should normally inspect one unified triage queue, not two forge inboxes.

Human duties:

- reject spam/obvious duplicates or request missing provenance;
- route serious artifacts to the required reviewer class;
- recruit/approve appropriate independent reviewers;
- decide governance conflicts and appeals;
- approve a canonical status transition only when required evidence/review exists;
- periodically reconsider frontier priorities with domain experts.

Do not personally certify mathematics outside your competence merely because you operate the repository.

## Jobs that should be automated

- GitHub -> GitLab source mirroring;
- dual-host source-SHA parity checks;
- Pages health and discovery endpoint checks;
- GitHub/GitLab intake discovery and normalization;
- source/version watches for Clay, OpenAI, registered arXiv papers, Prove2Me interface pin, and other registered primary sources;
- derived activity pages/counts;
- opening typed source-delta review candidates;
- routine deterministic builds/deployments after accepted canonical changes.

## Weekly view

Review:

- serious open attempts;
- artifacts awaiting qualified review;
- source-change alerts;
- duplicate/slop flags;
- forge parity;
- broken machine packets/endpoints.

## Monthly / milestone view

Review:

- whether P0/P1 frontier priority is still mathematically sensible;
- reviewer bottlenecks;
- whether agent output is reducing or increasing human review burden;
- real-user/PCSEI calibration evidence;
- whether Prove2Me or another platform has expanded enough that NSC should delegate more infrastructure instead of duplicating it.
