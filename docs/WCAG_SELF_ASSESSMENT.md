# WCAG self-assessment status

Scope: the static pages generated by this repository. Host-native issue/authentication interfaces are external services and are not included in this site's conformance statement.

Target: **WCAG 2.2 Level AA**, while retaining compatibility checks relevant to WCAG 2.1 Level AA.

## Automated/design review status

The current release has explicit checks or design review coverage for:

- non-text content: no informational images in the current release; decorative brand mark is hidden from assistive technology;
- information structure, sequence, headings, labels, unique IDs and duplicate attributes;
- language of page and marked English-language scientific blocks;
- Arabic right-to-left base direction;
- color use, text contrast, non-text boundary contrast and visible focus tokens;
- responsive layout design, text resizing design and logical CSS properties;
- keyboard-native controls, no custom drag interaction, no keyboard shortcuts, no autoplay or timed interaction;
- skip navigation on pages with repeated navigation;
- page titles and descriptive link labels;
- consistent navigation and identification;
- filter status updates through a polite live region;
- 44×44 CSS minimum for primary controls, exceeding WCAG 2.2's 24×24 minimum target-size criterion where that rule applies;
- reduced-motion support;
- no authentication, legal/financial transactions, or repeated-entry workflow implemented inside the static site.
