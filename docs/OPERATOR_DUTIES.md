# Operator duties after R15

## One-time duties

1. Complete any missing auth/bootstrap actions reported by `LOCAL_CAPABILITY_PREFLIGHT.py`.
2. Perform the human self-audit/submit step for a Prove2Me C/D proposal only after the executor presents the finished read-back packet and overlap-search receipt.
3. Add the dedicated GitLab mirror public deploy key if the executor cannot do so with existing authorization.

## Distribution duties

Use different entrances deliberately:

- general/technical audience: rich root `/`;
- mathematicians and hostile/skeptical expert readers: `/en/math/`;
- active researchers: `/en/frontier/`;
- reviewers: `/en/review/`;
- agent operators: `/en/agents/` plus discovery endpoint;
- formalizers: `/en/formalization/` and linked Prove2Me mission/theorems.

Initial success is not traffic. Seek:

- 2–5 credible PDE/analysis readers;
- 1–3 Lean/formal-method reviewers;
- first serious external attempt;
- first independent review;
- first accepted external contribution;
- first successful NSC -> Prove2Me -> NSC formal evidence loop.

## Ongoing duties

Inspect one unified triage queue. Human work is limited to:

- selecting/routing qualified reviewers;
- resolving governance conflicts or duplicate/priority disputes;
- checking semantic mapping and source attribution where required;
- approving a canonical state transition only after the required review exists;
- periodically reprioritizing the frontier when genuine evidence changes it.

Do not routinely mirror repos, redeploy Pages, copy GitLab issues, poll sources manually, or edit generated counts/pages. R15 automation owns those tasks.
