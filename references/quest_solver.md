# Quest Solver Protocol

1. Read the quest object and parent mission.
2. Resolve every source ID before making a sourced claim.
3. Check dependencies. If an unmet dependency blocks the task, report that fact rather than improvising around it.
4. Open a non-exclusive attempt.
5. Produce exactly the listed deliverables.
6. Test each acceptance condition.
7. Publish artifact identity, reproduction instructions, limitations, provenance, and conflicts.
8. Submit a result and request the named review class.

Do not claim the parent mission is solved unless its own acceptance criteria are satisfied and independently reviewed.
