# Roadmap and Release Classes

## Current: 0.4 open beta

Goal: a real public collaboration workspace that can recruit humans and agents immediately.

Open-beta launch gate requires:

- canonical public SSOT and versioned schemas;
- missions and bounded quests with every mission represented;
- a visible bounded task ladder and Initial Independent Review Portfolio;
- claim, result, review, and governance semantics;
- forge-native attempt/result/review/proposal flows;
- machine-readable agent discovery;
- deterministic site generation and passing repository release checks;
- explicit public/private boundary;
- truthful locale and external-review status.

The open beta does not claim that external scientific, legal, accessibility, localization, or security certification has occurred.

## Evidence maturation during beta

Priority outcomes:

1. independent Lean/source reproduction;
2. substantive mathematical/semantic review;
3. public-science, visualization, accessibility, browser, or agent-evaluation artifact;
4. first accepted contribution record end to end;
5. first community-proposed quest promoted through public RFC;
6. native-language review of currently pending scientific translations.

## 0.5 to 0.9

Promote features only when real use justifies them: richer dependency graphs, review dashboards, notification feeds, standardized artifact bundles, ORCID/DOI metadata, stronger provenance, and additional forge automation.

MCP/A2A or a first-party transactional service is optional until static discovery plus forge-native writes become an observed bottleneck.

## 1.0 institutional release

Version 1.0 requires the independent evidence appropriate to the claims made at launch. Expected gates include scientific review, formal-method review, numerical/CFD review where claimed, native-language signoff for production localization claims, real assistive-technology and disabled-user evaluation, multi-engine browser validation, production repository/security review, legal/IP/privacy review, and a named governance structure beyond bootstrap-maintainer mode.

These gates intentionally do not prevent the public beta from gathering the evidence and collaborators needed to satisfy them.
