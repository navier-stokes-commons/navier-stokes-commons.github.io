# Internationalization

The site has 16 statically addressable locale entry points. `lang`, `dir`, `hreflang`, UTF-8, logical CSS properties, and Arabic RTL layout are generated from public locale metadata.

## Translation status

**Canonical locale:** English.

**Full-translation, scientific-review-pending set inherited from the prior release:** Spanish, Brazilian Portuguese, French, Arabic, Simplified Chinese. These translations are shipped as useful public surfaces, but this artifact contains no independent native-language plus subject-domain signoff receipt, so it does not label them scientifically reviewed.

**Interface-preview set:** German, Italian, Russian, Hindi, Bengali, Japanese, Korean, Swahili, Turkish, Indonesian.

Preview locales localize the principal navigation/onboarding surface but retain scientific mission text in canonical English until a native scientific editor and domain reviewer establish semantic equivalence. Preview status is explicit in `content/public/project.json` and rendered on every preview-locale page. Canonical-English mission content in preview locales carries explicit `lang="en" dir="ltr"` boundaries where it is inherited. Preview status is not represented as completed translation.

Binding acceptance criteria remain canonical English in every non-English edition and carry `lang="en" dir="ltr"` boundaries for assistive technologies.

A locale graduates from preview only after native-language, scientific-semantic, bidi/typographic (where applicable), and accessibility review.
