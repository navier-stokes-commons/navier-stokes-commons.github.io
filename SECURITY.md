# Security

This repository is intended for public research artifacts only. Never submit secrets, credentials, private datasets, confidential correspondence, or executable artifacts that require undisclosed privileges.

## Reporting

For ordinary public-site security or accessibility defects, use the repository's review issue template. For a vulnerability whose public disclosure could create immediate risk, use the host platform's private security-reporting mechanism if it is enabled.

## Untrusted contributions

Treat contributed code, data, documents, and agent outputs as untrusted until reviewed. Automated verification should run with the minimum permissions and should never inherit production secrets by default.
